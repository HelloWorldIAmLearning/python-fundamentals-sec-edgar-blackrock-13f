## Python Fundamentals – SEC EDGAR Form 13F Analysis (BlackRock)

This project demonstrates core Python fundamentals through the analysis of **BlackRock’s Form 13F filings** sourced from the **SEC EDGAR** database.

### Key Concepts Covered
- File Input/Output (reading XML and CSV files)
- Python data types and data structures
- Data cleaning and transformation
- Data manipulation using Pandas and NumPy
- Basic data visualization using Matplotlib and Seaborn

### Data Sources
- SEC EDGAR – BlackRock Form 13F filings
- GitHub CUSIP reference data
- Kaggle company and industry mapping data

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
